# Factorio 2.1 compatibility

Preserves the existing prototype names and settings. Adapted to Factorio 2.1.24; private compatibility candidate. Uses recipe categories arrays and individual product probabilities; former electronics category remains craftable in assemblers and electromagnetic plants.

Original source: https://mods.factorio.com/mod/common-prototypes; original author: 5forSilver. Upstream license and assets retained.

Validation: native Factorio 2.1.24 fresh-world creation and isolated 1,200-tick probes. Quality families are tested separately; graphics and connected-client UI are not covered.

Public derivative common-prototypes-updated 1.0.0 preserves original authorship and license. Native migrates_from retains prototype identities and transfers owned objects; runtime controls adopt the complete original storage root. Literal prototype, setting, remote and metatable identifiers remain unchanged. Shared required dependencies and asset paths use the corresponding public derivative namespace. Original-ID feature validation remains in the private work directory; public native load validation is recorded separately.
