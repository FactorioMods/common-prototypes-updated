# Common Prototypes
The motivation of this mod is primarily so that multiple factorio mods can share similar items, and it all appears organic to the player. Sand is sand, wherever you get it. Trying to keep the resources simple and generic.

## Factorio 2.1 fork

This fork retains the shared materials for Factorio 2.1.24 and uses the matching Common Prototypes Graphics fork. Space Age and the declared graphics dependency are required.

Requires Factorio 2.1.24 or later. Disable `common-prototypes` before enabling this fork. Required content and optional integrations are listed in the mod dependencies.
